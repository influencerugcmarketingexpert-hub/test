## SECTION-BY-SECTION PURPOSE

| #  | Section              | Purpose                                             |
|----|----------------------|-----------------------------------------------------|
| 1  | Announcement bar     | Promo / shipping offer / urgency                    |
| 2  | Sticky nav           | Always-visible navigation + cart/wishlist/search    |
| 3  | Hero                 | First impression — brand promise + 2 main CTAs      |
| 4  | Trust strip          | Reduce buyer anxiety (shipping, returns, quality)   |
| 5  | Category tiles       | Help users self-segment by jacket type              |
| 6  | New arrivals         | Freshness — keep returning visitors interested      |
| 7  | Editorial split      | Force gender-based browsing (Men vs Women)          |
| 8  | Best sellers         | Social proof + safe choices for new buyers          |
| 9  | Brand story / craft  | Justify premium price — "why us"                    |
| 10 | Featured collection  | Push current seasonal drop                          |
| 11 | Custom CTA           | Differentiator — made-to-measure service            |
| 12 | Reviews              | Social proof with real photos                       |
| 13 | Press logos          | Authority / credibility                             |
| 14 | Instagram UGC        | Real customers + shoppable + community              |
| 15 | Blog / journal       | SEO + brand depth + style content                   |
| 16 | Newsletter           | Email capture (10% off bait)                        |
| 17 | Mega footer          | All links + payment + region                        |
| 18 | WhatsApp button      | Instant support — boosts conversion                 |

## MOBILE LAYOUT NOTES

On mobile (< 768px):
- Nav collapses to **hamburger menu** (☰) with slide-out drawer
- Category tiles stack to **2 per row** (instead of 6)
- Product carousels stay horizontal-swipe
- Editorial split stacks **vertically** (Men on top, Women below)
- Footer columns collapse to **accordions**
- WhatsApp button stays floating bottom-right
